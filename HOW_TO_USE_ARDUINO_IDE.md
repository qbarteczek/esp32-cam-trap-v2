# Jak uruchomić projekt w Arduino IDE (dla początkujących)

Jeśli nie chcesz korzystać ze środowiska inżynierskiego PlatformIO, ten projekt zawiera przygotowany kod, który uruchomisz łatwo w klasycznym programie Arduino.

1. Pobierz i zainstaluj [Arduino IDE](https://www.arduino.cc/en/software).
2. Otwórz folder `arduino_ide/` w tym repozytorium.
3. Znajdź podfolder z nazwą projektu i otwórz w nim plik o rozszerzeniu `.ino` klikając na niego dwukrotnie.
4. Program Arduino IDE się uruchomi. W zależności od projektu upewnij się, że masz zainstalowane odpowiednie biblioteki z **Menedżera Bibliotek** (np. Adafruit GFX, Adafruit AS7341, TFT_eSPI itp. - program pokrótce podpowie, czego brakuje).
5. Wybierz odpowiednią płytkę (np. ESP32 Dev Module lub AI Thinker ESP32-CAM) z menu Narzędzia -> Płytka.
6. Kliknij "Wgraj" (ikona strzałki w prawo).
